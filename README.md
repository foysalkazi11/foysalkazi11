#### How I engineer

- **Plan:** every feature starts as a written spec and plan (69 specs and 12 plans on kazilab).
- **Build:** AI coding agents implement inside a `CLAUDE.md` / `AGENTS.md` of project rules I maintain.
- **Verify:** I read the diffs; types, 92 test files, CI and Playwright checks on production decide what goes live.
- **Run:** scheduled agents keep two of my products updated after launch.
